# Source code for distributed releases

ProteomicsQC is distributed under the GNU General Public License version 3 only (`GPL-3.0-only`).

The corresponding source for each binary release is available from:

https://github.com/khompetsh2-cloud/ProteomicsQC_GUI/releases

Use the source archive attached to the release whose version matches the installer or portable package. The archive contains the application source, build and packaging scripts, dependency declarations, tests and documentation required to understand and rebuild ProteomicsQC.

The portable package also retains Python source and package metadata under `_internal`, but the release source archive is the preferred form for modification.

If a binary copy was supplied without access to its matching source archive, request the exact source from the distributor of that binary.
