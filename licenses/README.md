# Third-party licenses

- `PMultiQC-MIT.txt` is the license shipped by PMultiQC.
- `MultiQC-GPL-3.0.txt` identifies MultiQC and points to the complete GPLv3 text in the root `LICENSE` file and bundled package metadata.
- `CPython-License.txt` is copied from the exact CPython runtime by `tools/build_windows.py` when a portable or installer payload is built.
- Licenses for all other bundled Python packages remain in their `.dist-info` metadata directories.

These files document third-party components; they do not replace the original package metadata or alter any component's license.
